# ArrayMannger · 一维数组管理器

> 我的第一个小项目，一个一维数组管理器。目前还很简陋，可以说是一个初学者堆出来的屎山。
> 本文件只列出框架，具体实现请看源码。

---

## 一、目录结构

```
ArrayMannger/
├── README.md                 本文件
├── ArrayMananger-UTF8.c      UTF-8 编码源码
└── ArrayMananger-GBK.c       GBK 编码源码（中文 Windows 控制台用）
```

两份源码内容完全相同，只有编码不同，任选一份编译即可。

---

## 二、功能一览

| 序号 | 功能 | 说明 |
| :--: | --- | --- |
| 1 | 显示当前数组 | 按位置逐个输出全部元素 |
| 2 | 重新输入数组 | 重新指定长度并重新录入所有元素 |
| 3 | 统计信息 | 总和、平均值、最大值、最小值 |
| 4 | 升序排序并输出 | 冒泡排序（升序） |
| 5 | 降序排序并输出 | 冒泡排序（降序） |
| 6 | 查找某个值 | 出现次数 + 所有出现位置 |
| 7 | 删除指定位置的元素 | 后续元素前移，长度减一 |
| 8 | 在指定位置插入一个元素 | 指定位置之后元素后移，长度加一 |
| 9 | 删除所有等于指定值的元素 | 删除全部匹配项 |
| 10 | 数组去重 | 重复元素只保留第一次出现的位置 |
| 0 | 退出程序 | 结束运行 |

## 三、编译与运行

1. 用 IDE（Dev-C++ / VS Code / Code::Blocks 等）打开**任选一份** `.c` 文件；
2. 编译器标准选 C11；
3. 编译后直接双击 `.exe` 运行。

> - 系统：Win10 / Win11（更旧的 Windows 版本应该也能跑）。
> - 程序启动后**先完成初始化**（输入数组长度 → 依次输入各元素），之后才进入功能菜单。
> - 请根据自己需要选择适合自己的文件编码版本。

---

## 四、输入约束

| 项目 | 约束 |
| --- | --- |
| 数组长度 | 整数，1 ~ 100 |
| 数组元素 | 双精度浮点数，-10000 ~ 10000 |
| 菜单选项 | 整数，0 ~ 10 |
| 位置索引 | 对用户从 1 开始计数 |

所有输入都经过统一的校验函数，非法输入不会崩溃，只会提示后要求重新输入；`nan`、小数（在要求整数的场合）、超范围、非数字字符都会被拒绝。

## 五、源码框架

### 1. 全局定义（文件顶部）

| 宏 | 当前值 | 含义 |
| --- | --- | --- |
| `MAX_LENGTH` | 5 | 数组最大长度 |
| `MIN_LENGTH` | 1 | 数组最小长度 |
| `MIN_VALUE` | -10000 | 元素允许的最小值 |
| `MAX_VALUE` | 10000 | 元素允许的最大值 |
| `MIN_NUM_FUNCTION` | 0 | 菜单选项最小值 |
| `MAX_NUM_FUNCTION` | 10 | 菜单选项最大值 |
| `NUM_TAG` | 100000 | 去重用的哨兵标记值 |

全局变量：`array_length`（当前长度）、`user_function_choice`（当前选择）、`array[]`（数组本体）。

### 2. 函数框架      AIGC内容，请谨慎辨别！

| 函数 | 作用 |
| --- | --- |
| `clear_buffer()` | 清空键盘缓冲区，防止残留字符影响下一次输入 |
| `int_get_input(min, max)` | 读取并校验一个整数输入 |
| `double_get_input(max, min)` | 读取并校验一个浮点数输入 |
| `print_menu()` | 打印主菜单并返回用户选择 |
| `function_start()` | 打印「你选择了功能 N」的提示 |
| `function_over()` | 分支统一收尾：暂停 + 清屏，返回主菜单 |
| `bubble_sort(arr, n)` | 升序冒泡排序 |
| `reverse_bubble_sort(arr, n)` | 降序冒泡排序 |
| `array_print()` | 按位置输出当前数组 |
| `main()` | 初始化输入 + `while(1)` 主循环 + `switch` 功能分发 |

### 3. 主流程    AIGC内容，请谨慎辨别！

```
main()
 ├── 打印欢迎信息与各项约束
 ├── 输入数组长度（int_get_input）
 ├── 循环输入每个元素（double_get_input）
 └── while(1)
      ├── print_menu() 取用户选择
      ├── switch(选择)
      │    ├── case 0  → 退出
      │    ├── case 1  → 显示数组
      │    ├── case 2  → 重新输入数组（restart 标号，供功能 9 复用）
      │    ├── case 3  → 统计信息
      │    ├── case 4  → 升序排序
      │    ├── case 5  → 降序排序
      │    ├── case 6  → 查找值
      │    ├── case 7  → 按位置删除
      │    ├── case 8  → 按位置插入
      │    ├── case 9  → 按值删除全部
      │    ├── case 10 → 去重
      │    └── default  → 提示功能码错误
      └── 各分支结束后 function_over() 返回菜单
```

## 六、实现要点（简）

- **输入校验统一封装**：`int_get_input()` / `double_get_input()` 负责全部读取，防止被scanf和键盘输入缓冲区肘击
- **正序/倒序冒泡排序**： 在函数宏定义阶段定义的两个函数
- **标记去重法**： 功能10所需的算法

---

## 七、已知问题     含AIGC内容，请谨慎辨别！

1. GCC 加 `-Wall -Wextra` 会有两处 `statement with no effect` 警告（功能 7、9 的 `for (num_location; ...)`），不影响运行。
2. function_start在case9 goto case2 时，会打印错误的功能选择提示。
3. case9 存在可能使数组处理长度小于MIN_LENGTH。
