# C语言学习过程仓库

> **本仓库用于记录我的 C 语言学习过程。**
> 这本仓库中包含我的C语言学习过程中一些练习的小项目，有的甚至无法被称之为项目。总之，它们都很简陋就是了


所有项目（除过PTA作业）包含两份**内容完全相同、仅文件编码不同**的源码

---

## 目录结构

```
.
├── README.md                    本说明文档（仓库说明文档）
├── studentwork                  PTA作业
├── .gitignore                   忽略编译产物
└── project/
    └── 项目名称      子级文件夹，用于分类各个不同的项目
        ├── README.md       项目的说明文档
        └── 项目源代码       项目源代码,有中文的话会存两份UTF-8编码和GBK编码
```
